# i18n (Tiếng Việt / English) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:**
- Every user-facing string comes from typed `vi`/`en` tables.
- The language follows the device by default, can be overridden on a new Settings screen (which also hosts the theme choice), and persists.

**Architecture:**
- `src/settings/settings.ts` replaces `src/theme/preference.ts`. It holds `{theme, language}` in `settings.json`, and saves are serialized read-merge-writes.
- `src/i18n/{vi,en,language}.ts` are pure modules. `en` has the type `typeof vi`.
- `LocaleProvider`/`useLocale()` resolves the preference plus `expo-localization`'s device language.
- Screens call `const { t } = useLocale()`.
- Non-React helpers take strings as parameters.

**Tech Stack:** Expo SDK 57, RN 0.86, expo-router 57, expo-localization (new, `npx expo install`), Jest with RNTL v14 (async `render`/`fireEvent`/`act`).

**Spec:** `docs/superpowers/specs/2026-10-07-i18n-design.md`

## Global Constraints

- **Vietnamese copy is unchanged from 1.3.0.** Every `vi` value is the exact current literal, so existing tests keep their Vietnamese assertions.
- `useLocale()` outside a provider returns `{ t: vi, language: 'vi', preference: 'system', setPreference: no-op }`.
- `src/i18n/vi.ts`, `en.ts`, `language.ts`, `src/settings/settings.ts` and `src/utils/format.ts` must not import React or React Native. Use relative imports only. Never edit `ios/` or `android/`.
- **Language names** in both tables: `Tiếng Việt`, `English`.
- **Fixed English copy:**
  - `Scan document`, `Merge PDF`, `Settings`, `Appearance`, `Language`, `System default`, `Light`, `Dark`;
  - camera permission: `iScanner needs camera access to scan documents.`;
  - merge prefix `Merge`.
- **Date formats:** `vi` → `dd/MM/yyyy HH:mm`, `en` → `MM/dd/yyyy HH:mm`. `defaultName` keeps its date part (`05-10-2026 14.03`) and only the prefix changes.
- Version 1.4.0, `android.versionCode` 4, `ios.buildNumber` "4".
- Do not touch `.gitignore`, `.claude/`, `docs/claude-memory/`, `requirement/` or `New folder/`.
- `npm test` and `npm run typecheck` pass at the end of every task. There is no lint setup.

## Review Focus

1. **Theme and language saved back-to-back.** The user taps `Tối` then `English` quickly. Expected: both persist. Pinned in Task 1 (concurrent `saveSettings` test).
2. **An old `settings.json` holding only `{"theme":"dark"}`.** Expected: theme dark, language system. Pinned in Task 1.
3. **A Vietnamese literal left in UI code after migration.** Expected: the guard test fails. Pinned in Task 5 (guard), run over all UI files.
4. **Device language `vi-VN`, `null` or a non-vi/en code** (e.g. `fr`). Expected: `vi`, `en`, `en`. Pinned in Task 2.
5. **A shared file with no usable name.** It used to show the hard-coded `Tài liệu`. Expected: the localized untitled label is shown and used as the saved name. Pinned in Task 5 (incoming test with an empty name, in `en`).
