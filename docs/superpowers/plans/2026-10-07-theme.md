# Light / Dark / System Theme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Users pick `Theo hệ thống` / `Sáng` / `Tối` from a ⚙︎ button in the library header. The whole app (screens, headers, status bar, native dialogs) follows the choice, system mode follows the device live, and the choice persists.

**Architecture:**
- `Appearance.setColorScheme` overrides the native scheme app-wide.
- A theme context exposes the effective scheme (`useColorScheme()`) and a palette through `useTheme()`.
- The preference is stored as `settings.json` through the existing `FsAdapter` (`expoFs`).
- Screens move their colors into `makeStyles(colors)`, memoized per palette.

**Tech Stack:** Expo SDK 57, RN 0.86, expo-router 57 (`ThemeProvider`, `DarkTheme`, `DefaultTheme` exported from `expo-router`), expo-status-bar, expo-system-ui (new), Jest with RNTL v14 (async `render`/`fireEvent`/`act`).

**Spec:** `docs/superpowers/specs/2026-10-07-theme-design.md`

## Global Constraints

- All user-facing copy is Vietnamese. The exact strings are `Giao diện`, `Theo hệ thống`, `Sáng`, `Tối`, `Huỷ`, and the selected mark is the prefix `✓ `.
- Routes live in `app/`. Logic lives in `src/`, and `src/theme/palette.ts` and `src/theme/preference.ts` must not import React or React Native. UI lives in `src/components/`. Use relative imports only.
- Install native and Expo packages with `npx expo install` only (npm). Never touch `ios/` or `android/`.
- Do not touch `.gitignore`, `.claude/`, `docs/claude-memory/`, `requirement/` or `New folder/`.
- `npm test` and `npm run typecheck` must pass at the end of every task. There is no lint setup, so never run `expo lint`.
- The page editor (`PageEditor`, `CornerHandles`), `PagePreview`, and the scan processing overlay (black scrim, white text and spinner) keep their current colors.
- `useTheme()` outside a provider returns the light palette, `scheme: 'light'`, `preference: 'system'` and a no-op `setPreference`, so existing screen tests render unchanged.

## Review Focus

1. **Screens are covered, but any `Text` without an explicit color stays black on dark.** Expected: every visible `Text` and `TextInput` in a themed screen gets `colors.text` or `colors.textMuted`. Pinned by the dark-render tests in Tasks 4 and 5, which check the text color on a representative label.
2. **The preference file holds garbage or an unknown value** (e.g. `{"theme":"blue"}`, `not json`). Expected: `system`, with no crash. Pinned in Task 1.
3. **The save fails while choosing a theme.** Expected: the theme still applies and nothing throws. Pinned in Task 2.
4. **The document long-press menu regresses after the ActionMenu extraction.** Expected: the same labels and actions, with backdrop and back closing it. Pinned in Task 3.
5. **The device theme changes while the app is in system mode.** Expected: a live re-render with the new palette. Pinned in Task 2 (the mocked `useColorScheme` flips and the colors change) and verified on the emulator in Task 6.

**Interfaces:**
- Consumes: `useTheme()` and `Palette` (Tasks 1–2).
- Pattern, used for every file in Tasks 4–5:
  - layout stays in a module-level `StyleSheet.create`;
  - colors come from `const makeStyles = (c: Palette) => StyleSheet.create({...})`;
  - in the component: `const { colors } = useTheme(); const themed = useMemo(() => makeStyles(colors), [colors]);`
  - combine as `style={[styles.x, themed.x]}`.

Color mapping:

| Current | Token |
|---|---|
| `#fff` backgrounds | `background`, or `surface` for rows, dialogs and sheets |
| `#666`, `#555`, `#333` labels | `textMuted` |
| `#1f6feb` | `primary` |
| `#fff` text on a button | `onPrimary` |
| `#d1242f` | `danger` |
| `#ddd`, `#ccc` borders | `border` |
| `#eee` thumbnail | `placeholder` |
| `#eef4ff` | `surfaceActive` |
| `rgba(0,0,0,0.4)` dialog backdrop | `backdrop` |

Text that has no color today gets `text`. `TextInput` gets `color: text` and `placeholderTextColor={colors.textMuted}`.
